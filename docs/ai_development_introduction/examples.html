サンプルコード一覧

本書で使ったサンプルコードの一覧である。ファイル名のリンクからダウンロードできる。各ファイルの内容と解説は、表の「掲載箇所」の章で閲覧できる。

実行の準備

Python のサンプルは、実際の LLM API の代わりに、応答を模擬するクライアント（llm_stub.py）を使う。そのため、API キーや外部のパッケージは不要で、Python 3.10 以上の標準ライブラリだけで実行できる。llm_stub.py を各サンプルと同じディレクトリに置いて実行する。

コード 1 サンプルの実行と静的解析
1$ python ex03_tool_agent.py
2$ pip install flake8 mypy   # 静的解析を行う場合
3$ flake8 .
4$ mypy *.py

静的解析の設定は setup.cfg にある。flake8 は行の長さを 120 文字まで許容し、mypy は strict モードで検査する。

llm_stub.py

各サンプルが共通に使う模擬クライアントである。LLMClient（45 〜 50 行目）は、サンプルが前提とするインターフェースである。ScriptedLLM はあらかじめ用意した応答を順に返し、RuleBasedLLM は入力に応じて応答を決める関数を使う。estimate_tokens（83 〜 91 行目）は、トークン数を簡易的に概算する。

コード 2 LLM を模擬するクライアント（llm_stub.py）
 1"""本書のサンプルで共通に使う、LLM を模擬するクライアント。
 2
 3実際の LLM API を呼ばずに動作を確認できるよう、応答をあらかじめ決めておく
 4``ScriptedLLM`` と、入力に応じて応答を決める ``RuleBasedLLM`` を用意する。
 5どちらも ``LLMClient`` プロトコルを満たすため、同じインターフェースを持つ
 6実 API のクライアントに差し替えられる。
 7"""
 8
 9from __future__ import annotations
10
11from collections.abc import Callable, Iterable, Sequence
12from dataclasses import dataclass
13from typing import Literal, Protocol
14
15Role = Literal["user", "assistant", "tool"]
16
17
18@dataclass(frozen=True)
19class ToolCall:
20    """モデルが要求したツール呼び出し。"""
21
22    call_id: str
23    name: str
24    arguments: dict[str, str]
25
26
27@dataclass(frozen=True)
28class Message:
29    """会話履歴の 1 件分のメッセージ。"""
30
31    role: Role
32    content: str
33    tool_calls: tuple[ToolCall, ...] = ()
34    tool_call_id: str | None = None
35
36
37@dataclass(frozen=True)
38class Response:
39    """モデルの応答。ツール呼び出しを含む場合がある。"""
40
41    text: str
42    tool_calls: tuple[ToolCall, ...] = ()
43
44
45class LLMClient(Protocol):
46    """サンプルが前提とする LLM クライアントのインターフェース。"""
47
48    def complete(self, system: str, messages: Sequence[Message]) -> Response:
49        """システムプロンプトと会話履歴を受け取り、応答を返す。"""
50        ...
51
52
53class ScriptedLLM:
54    """あらかじめ用意した応答を順番に返すクライアント。"""
55
56    def __init__(self, responses: Iterable[Response]) -> None:
57        self._responses = list(responses)
58        self.call_count = 0
59
60    def complete(self, system: str, messages: Sequence[Message]) -> Response:
61        if self.call_count >= len(self._responses):
62            raise RuntimeError("用意した応答をすべて使い切った")
63        response = self._responses[self.call_count]
64        self.call_count += 1
65        return response
66
67
68Rule = Callable[[str, Sequence[Message]], Response]
69
70
71class RuleBasedLLM:
72    """入力（システムプロンプトと会話履歴）から応答を決める関数を使うクライアント。"""
73
74    def __init__(self, rule: Rule) -> None:
75        self._rule = rule
76        self.call_count = 0
77
78    def complete(self, system: str, messages: Sequence[Message]) -> Response:
79        self.call_count += 1
80        return self._rule(system, messages)
81
82
83def estimate_tokens(text: str) -> int:
84    """トークン数を概算する。
85
86    実際のトークン数はモデルのトークナイザーによって異なる。ここでは
87    ASCII 文字は 4 文字で 1 トークン、それ以外の文字は 1 文字で 1 トークンとみなす。
88    """
89    ascii_chars = sum(1 for ch in text if ch.isascii())
90    other_chars = len(text) - ascii_chars
91    return (ascii_chars + 3) // 4 + other_chars

実際の API に差し替えるには、LLMClient と同じ complete メソッドを持つクラスを作る。コード 3 は、Anthropic の Python SDK（anthropic パッケージ）を使う例である。ツール呼び出しの変換は省略している。

コード 3 実際の API を使うクライアントの例（ツール呼び出しの変換は省略）
 1from collections.abc import Sequence
 2
 3import anthropic
 4
 5from llm_stub import Message, Response
 6
 7
 8class AnthropicLLM:
 9    def __init__(self, model: str = "claude-opus-5-5") -> None:
10        self._client = anthropic.Anthropic()  # 環境変数 ANTHROPIC_API_KEY を使う
11        self._model = model
12
13    def complete(self, system: str, messages: Sequence[Message]) -> Response:
14        result = self._client.messages.create(
15            model=self._model,
16            max_tokens=2048,
17            system=system,
18            messages=[{"role": m.role, "content": m.content} for m in messages if m.role != "tool"],
19        )
20        text = "".join(block.text for block in result.content if block.type == "text")
21        return Response(text)
