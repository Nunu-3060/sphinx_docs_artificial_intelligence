機械学習・深層学習入門

本書は、人工知能の開発を専門としないが Python を使い慣れたエンジニアに向けて、機械学習と深層学習の仕組みを解説する入門書である。数式・図・動くコードの 3 つを組み合わせ、「モデルが内部で何をしているのか」を納得しながら読み進められるように構成した。
